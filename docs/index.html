迷わない入力切替を。

文字を打つ前に、いまどちらの入力モードかを確認する。KanaEn は、その小さな摩擦をなくします。

Command を単押ししたときだけ動作するため、⌘C や ⌘V、クリックやスクロールには干渉しません。

Simple by design

必要なことだけ。
余計なものはなし。

01

軽量なネイティブアプリ

AppKit と macOS 標準 API だけで動作。サードパーティライブラリやドライバは使いません。

02

いつもの操作を邪魔しない

ほかのキー、クリック、スクロールと一緒に Command を使った場合、入力ソースは切り替わりません。

03

静かに常駐

Dock アイコンなし。メニューバーのアイコンも非表示にでき、ログイン時起動にも対応しています。

04

プライバシーを尊重

イベントは読み取り専用で監視。キー入力の保存、ネットワーク通信、テレメトリはありません。
